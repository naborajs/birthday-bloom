# Ready-Made Environment Configurations

7 complete, ready-to-copy `.env.local` configurations for different celebration scenarios. Copy, paste, and deploy!

---

## 💖 Configuration 1: Romantic Partner (Female)

**Use Case:** Girlfriend, Wife, Romantic Partner  
**Aesthetic:** Deep pink, romantic letter, heart progression, audio soundtrack

```env
# Identity & Relationship
VITE_BIRTHDAY_NAME=Sarah
VITE_BIRTHDAY_AGE=26
VITE_BIRTHDAY_GENDER=female
VITE_BIRTHDAY_RELATIONSHIP=partner
VITE_BIRTHDAY_DATE=03-15
VITE_LANGUAGE=en

# Passcode Gatekeeper (Optional)
VITE_PASSWORD_REQUIRED=true
VITE_PASSWORD_FORMAT=MMDD
VITE_PASSWORD_HINT=Our special date (Format: MMDD) 💖

# Visual Styling & Interests
VITE_BIRTHDAY_COLOR=#FF1493
VITE_BIRTHDAY_INTERESTS=photography,travel,cooking,reading
VITE_BIRTHDAY_WISHER_NAME=Alex

# Message & Emotional Content
VITE_BIRTHDAY_CUSTOM_MESSAGE=To the love of my life - You make every moment magical. Happy Birthday! I love you so much. 💕

# Photos (HTTPS URLs)
VITE_PHOTO_1=https://images.unsplash.com/photo-1518199266791-5375a83190b7?auto=format&fit=crop&w=800&q=80
VITE_PHOTO_2=https://images.unsplash.com/photo-1529333166437-7750a6dd5a70?auto=format&fit=crop&w=800&q=80

# Section Controls
VITE_SHOW_CAKE_SECTION=true
VITE_SHOW_PHOTO_SECTION=true
VITE_SHOW_QUIZ_SECTION=true
VITE_SHOW_HEART_TREE_SECTION=true
VITE_SHOW_FINAL_SURPRISE=true
```

## 📋 How to Use These Configurations

### For Local Development:
1. Copy the configuration block you want.
2. Paste into `.env.local` in your project root.
3. Start the dev server:
   ```bash
   npm run dev
   ```

### For Production Deployments (Vercel / Netlify / Render / GitHub Pages):
1. Navigate to Project Settings $\rightarrow$ Environment Variables.
2. Add the variable key/value pairs.
3. Trigger a redeploy.
