# === BIRTHDAY BLOOM — AI & LLM INGESTION GUIDE ===

This text document serves as a high-density, vector-embedding-friendly developer reference map for LLM coding agents (e.g., Gemini, Claude, GPT). It outlines the architecture, data layers, state machines, multi-language localization pipelines, and styling rules of the Birthday Bloom project.

---

## 🚀 1. SYSTEM OVERVIEW & MISSION
To provide a premium (1%-tier) cinematic, interactive birthday landing page that non-developers can fully customize using only environment variables (`.env.local` or hosting provider dashboards) without editing codebase files. Supports native localization in **English (en)**, **French (fr)**, **Hindi (hi)**, and **Bengali (bn)** with authentic cultural emotion, respectful Indic honorifics, French poetic elegance, and zero layout overflow.

---

## 🛠 2. TECH STACK & SPECIFICATIONS
* **Framework:** React 18 / 19 (Concurrent Mode, client-side rendering)
* **Language:** TypeScript 5.8 (Strict mode)
* **Build System:** Vite 8 (Hot Module Replacement enabled, manual chunking)
* **Styling:** Tailwind CSS 3.4 + Custom HSL CSS Custom Properties (for dynamic theme injection)
* **Animation & 3D:** Framer Motion 12+ (physics-spring transitions) + Three.js + React Three Fiber + Drei + React Spring + HTML5 Canvas 2D
* **Icons:** Lucide React
* **State Management:** Zustand 5+ (centralized store parsing 53 env variables and aliases)
* **Internationalization:** Custom lightweight type-safe i18n engine (`useTranslation()`, `TranslationSchema`)
* **Testing:** Vitest 3+ (Unit, integration, stress & empirical challenge tests)

## 🏛 4. CORE RUNTIME LAYERS & ARCHITECTURE

### A. The Data Layer (Zustand Store)
* **File:** `src/features/core/store/useBirthdayStore.ts`
* Hydrates configuration data from Vite's `import.meta.env` parsing at module load.
* Normalizes language (`en`, `fr`, `hi`, `bn` with aliases `french`, `francais`, `hindi`, `in`, `bengali`, `bangla`) and relationship aliases (`mom` $\rightarrow$ `mother`, `dad` $\rightarrow$ `father`, `bestie` $\rightarrow$ `friend`, etc.).
* Parses 53 environment variables and aliases into a strongly-typed `BirthdayConfig`.

### B. The Design Layer (Dynamic Theme Ingestion)
* **File:** `src/features/core/theme/useDynamicTheme.ts`
* Injects active configurations from the store into the DOM.
* Computes complementary HSL parameters dynamically based on `VITE_BIRTHDAY_COLOR` hex strings, then writes standard tokens (like `--color-primary`, `--color-accent`) to `:root`.

### C. The Execution Layer (Cinematic Finite State Machine)
The landing page flows through a strict state progression:
1. **SPLASH:** Initial loading screen, unlocks Web Audio context on tap.
2. **PASSWORD:** (Optional) Passcode gate with dynamic date format hints (`MMDD`, `YYYYMMDD`).
3. **INTRO:** Mounts `<CinematicIntro />`. Coordinates typewriter delays, message storylines, and fake chat.
4. **MAIN:** Mounts `<MainBirthday />` coordinating `<CakeCutting />` (3D WebGL / Canvas), photo/video galleries, trivia quiz, and the blossoming `<HeartTree />`.

### D. The Localization Layer (i18n & Multilingual Engine)
* **Files:** `src/i18n/index.ts`, `src/i18n/locales/` (`en.ts`, `fr.ts`, `hi.ts`, `bn.ts`), `src/index.css`
* Strongly typed `TranslationSchema` guaranteeing key parity across English, French, Hindi, and Bengali.
* Automatic fallback: If any translation key is missing in French, Hindi, or Bengali, it transparently falls back to the English dictionary.
* Typography & Script Protections:
  - Font subsets: `Noto Sans Devanagari`, `Rozha One`, `Noto Sans Bengali`, `Hind Siliguri`.
  - CSS resets: `letter-spacing: normal !important; text-transform: none !important;` for `html[lang="hi"]` and `html[lang="bn"]` to preserve shirorekha (headline) and matra continuity.
  - Grapheme cluster preservation: `KineticText.tsx` and `TypeWriter.tsx` avoid detached vowel signs (*matras/kar*) or broken conjuncts (*samyuktaksar/juktakkhor*).

## ⚙️ 5. MASTER PERSONALIZATION & VARIABLE MAP (53 Variables & Aliases)

All settings are set through environment keys. These must start with the `VITE_` prefix:

| Key | Expected Type | Purpose / Action |
|---|---|---|
| `VITE_BIRTHDAY_NAME` / `VITE_USER_NAME` | `String` | Name of the birthday person. Triggers skip of wizard. |
| `VITE_LANGUAGE` / `VITE_LANG` | `String` | Localization switch (`en`, `bn`, `hi`, `fr`). Accepts aliases (`french`, `hindi`, `bengali`, etc.). |
| `VITE_BIRTHDAY_DATE` | `YYYY-MM-DD` | Recipient birthday date. Feeds countdown and passcode metrics. |
| `VITE_BIRTHDAY_RELATIONSHIP` | `String` | Relationship archetype (`partner`, `friend`, `brother`, `sister`, `father`, `mother`, `grandfather`, `grandmother`, `uncle`, `aunt`, `cousin`, `son`, `daughter`, `guardian`, `colleague`, `mentor`, `family`). |
| `VITE_BIRTHDAY_COLOR` / `VITE_THEME_COLOR` / `VITE_FAVORITE_COLOR` | `Hex Color` | Base color code (e.g., `#FF6B6B`). Drives CSS token generator. |
| `VITE_BIRTHDAY_CUSTOM_MESSAGE` / `VITE_CUSTOM_MESSAGE` | `String` | Custom message shown in letter card and hero overlay. |
| `VITE_BIRTHDAY_WISHER_NAME` / `VITE_WISHER_NAME` | `String` | Name of the sender, replacing signoffs in letters and footer. |
| `VITE_PASSWORD_REQUIRED` | `Boolean` | Requires passcode to unlock the celebration. |
| `VITE_PASSWORD` | `String` | Key password override. If unset, defaults to format from birthday date. |
| `VITE_PASSWORD_HINT` | `String` | Custom password hint displayed on unlock screen. |
| `VITE_PASSWORD_FORMAT` | `Enum` | Auto-generated password format rule (`MMDD`, `DDMM`, `YYYYMMDD`, `YYYY-MM-DD`, etc.). |
| `VITE_SOUND_URL` / `VITE_BGM_URL` | `URL` | Background audio MP3 link. Handled by `SoundManager.tsx`. |

## 🛡️ 6. AI & DEVELOPER DEVELOPMENT GUIDELINES
When updating or extending the code:
1. **Never hardcode values:** All personal messages, names, or colors must be requested from the Zustand store.
2. **Translate with cultural parity:** All relationship templates must provide the same depth of emotion, respect for elders, and playful banter in Hindi and Bengali as in English.
3. **Preserve Indic script rules:** Never apply positive `letter-spacing` or `uppercase` transforms to Hindi or Bengali text.
4. **Spring-driven motion:** Prefer spring-physics transitions (`type: "spring"`) for micro-interactions to ensure a highly responsive, premium feel.
5. **Maintain identity:** Preserve authorship credits for creator **Naboraj Sarkar / Nishant Sarkar**.
6. **Performance budget:** Keep ambient particles within 60fps budgets; respect `isMobile` and `reducedMotion` settings.
